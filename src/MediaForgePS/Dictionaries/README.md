# Hunspell dictionaries

## en_US

Bundled English Hunspell dictionary (`en_US.dic` / `en_US.aff`) sourced from
[wooorm/dictionaries](https://github.com/wooorm/dictionaries) (`dictionary-en`),
generated from [SCOWL / wordlist.aspell.net](http://wordlist.aspell.net/dicts/).

License: MIT AND BSD (compatible with this project's Apache-2.0 license).

## Spell-check engine

Spell checking uses [WeCantSpell.Hunspell](https://www.nuget.org/packages/WeCantSpell.Hunspell/),
a managed Hunspell port under the Hunspell MPL/LGPL/GPL tri-license.
